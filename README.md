## What it does

`main.py` writes one smart-fridge roast to `/output/entry.txt`:

> My fridge updated itself overnight and now the ice maker needs a subscription. I bought an appliance, not a SaaS product with a door.

The roast is fixed and deterministic — the same text is written on every run.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Why this roast

- It is aimed squarely at the fridge itself: a firmware update that turns
  the ice maker into a subscription.
- The punchline lands on the last phrase: "a SaaS product with a door."
- It is specific to smart fridges — the update, the ice maker, the
  subscription — not a generic gadget gag.
- It is tight (133 characters) with no setup the punchline does not need.
- It dodges the obvious cracks about the fridge ordering groceries or
  watching you.
